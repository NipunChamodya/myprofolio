# My Portfolio Website

This is my **personal portfolio** website developed using **HTML** and **CSS**. It highlights my profile, skills, projects, and provides contact information — all in a clean and responsive layout.

 **Live Site:** [https://nipun.online](https://nipun.online)

---

## Installation

### Before You Start

To view this project locally, you need:

- A modern web browser (Chrome, Firefox, Edge, etc.)
- (Optional) A code editor like VS Code

---

### ⚙️ Steps

1. **Clone the repository**

```bash
git clone https://github.com/NipunChamodya/myprofolio.git

cd myprofolio

```
---

## Open the index.html file

### You can either:

- Double-click index.html
- OR open it with a live server (recommended if you're using VS Code)
